# Borrowed Face

A single full-screen collage with movable facial features and connecting lines. All visible titles, captions, navigation, controls, and descriptive text have been removed at the artist’s request. Keyboard instructions and descriptive alt text remain available to screen readers.

The composition uses an invisible CSS Grid to position images. Native JavaScript handles dragging and arrow-key movement. The previous page URLs redirect to the single collage. The earlier three-page version is preserved in Git history at commit `21e27be`.
